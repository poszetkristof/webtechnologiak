Flexbox

Egy doboz, ami elrendezi és igazítja a benne lévő elemeket.

Görgess lefelé, vagy használd a ↓ ↑ billentyűket

1. A kiindulás

Egy doboz, benne 3 div

Alapból a div-ek egymás alá kerülnek, és kitöltik a teljes szélességet.

HTML
<div class="container">  <div class="item">1</div>  <div class="item">2</div>  <div class="item">3</div></div>

2. Egy sor CSS

display: flex

A dobozra írjuk (a szülőre), és a közvetlen gyerekeit rendezi el: egymás mellé kerülnek. Kapcsold ki-be!

CSS
.container {  display: flex;}
A doboz a flex konténer, a benne lévő elemek a flex elemek. A neve onnan jön, hogy rugalmas: az elemek a rendelkezésre álló helyhez igazodnak.

3. Két irány

Főtengely és kereszttengely

Mielőtt igazítunk, két irányt kell ismerni.

Főtengely: amerre az elemek sorakoznak. Alapból balról jobbra.

Kereszttengely: erre merőleges. Alapból fentről lefelé.

Minden igazítás valamelyik tengelyhez tartozik:
justify-content → főtengely
align-items → kereszttengely

kereszttengely

4. Igazítás a főtengelyen

justify-content

Hova kerüljenek az elemek a sorban, és hova a maradék hely?

CSS
.container {  display: flex;  justify-content: flex-start;}

5. Igazítás a kereszttengelyen

align-items

Hova kerüljenek az elemek a másik irányban? Itt most fent, középen vagy lent.

CSS
.container {  display: flex;  height: 240px;  align-items: stretch;}
Válts flex-start-ra: az elemek alapból különböző magasak (a tartalmuk szerint). A stretch (ez az alap) mindet kinyújtja a doboz teljes magasságáig, ezért lesznek egyformák. Ha egy elemnek megadott magassága van (pl. height: 50px a playgroundon), azt nem nyújtja meg.

6. A kettő együtt

A híres 3 sor: középre igazítás

A flexbox előtt egy elemet függőlegesen középre tenni nagyon nehéz volt. Most három sor. Utána próbálj ki más kombinációkat is!

CSS
.container {  display: flex;  justify-content: center; /* főtengely */  align-items: center;     /* kereszttengely */}

7. Ha nem férnek el

flex-wrap és gap

Alapból minden elem egy sorba kerül, és ha nincs elég hely, összemennek. A wrap megengedi, hogy új sorba törjenek. Húzd keskenyebbre a dobozt!

CSS
.container {  display: flex;  flex-wrap: nowrap;  gap: 8px;}
A gap csak az elemek közé tesz helyet, a doboz szélére nem. A kártyáknál ezzel lesz hely a lapok között.

8. Fordítsuk el!

flex-direction

Ez dönti el, merre sorakozzanak az elemek. Vele együtt a tengelyek is elfordulnak: column-nál a főtengely függőleges lesz.

CSS
.container {  display: flex;  flex-direction: row;  justify-content: flex-start;}
A justify-content mindig a főtengelyen igazít. Állítsd center-re, aztán válts column-ra: ugyanaz a tulajdonság, de most függőlegesen hat.

9. Egy elem kivételt kap

align-self

Az align-items mindenkire hat. Ha egyetlen elemet máshova akarsz tenni a kereszttengelyen, arra az elemre írd az align-self-et. Kattints egy elemre!

CSS
.container {  display: flex;  align-items: center; /* mindenki középen... */} .item:nth-child(2) {  align-self: flex-start; /* ...kivéve ezt */}
Mindkét feladatban kell: a playgroundon a vezérlőpanel ne nyúljon meg, a kártyákon a sarkok kerüljenek felülre és alulra.

Összefoglaló

display: flex

A dobozra (szülőre). A gyerekei egymás mellé kerülnek.

flex-direction

Merre sorakoznak: row (alap), column, -reverse.

justify-content

Igazítás a főtengelyen.

align-items

Igazítás a kereszttengelyen. Alap: stretch.

flex-wrap: wrap

Ami nem fér el, új sorba kerül.

gap

Hely az elemek között.

align-self

Egy elem kivételt kap a kereszttengelyen.

center + center

A híres 3 sor: display: flex + justify-content: center + align-items: center.
